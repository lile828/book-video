## 三、从 130 秒砍到 60 秒：删了什么，为什么

压缩不是等比缩水。原则是**保情绪骨架，砍所有铺垫、修饰、重复**。

| 原段落 | 处理 | 理由 |
|---|---|---|
| "这本书，是海伦·凯勒写的" 单独成段 | **合并**进身世首句 | 独立成段浪费 2 秒，且信息量为零 |
| "从此没有颜色，也没有回响" | **删** | 与"失去光、失去声音"重复，二选一 |
| 水井段原 9 行（一遍/又一遍/同时…） | **压成 4 行** | 原版是情绪高点但太占时间，60 秒版只留"蹲在水井边／写下水的名字"这个画面 |
| "后来她读了大学，写下了这本书" | **删** | 学历信息对情绪无贡献，长版里保留即可 |
| "书里最动人的，不是她有多苦" 独立两行 | **保留** | 这是转折预埋，不能删 |
| 三天段落原含"婴儿的眼睛／老师的、朋友的、母亲的／看一场戏" | **压成每天一行** | 三天必须压缩，否则 60 秒装不下；每天用最强的一个画面代表 |
| "黑暗会让他更珍惜光，寂静会教他懂得声音" | **删（移到长版）** | 原文明句，但在 60 秒里属于"第二个道理"，会稀释森林之问的冲击 |
| "一辈子可以听雨，可我们戴着耳机" | **删** | 保留"看日出/不抬头"一句即可，两句对照在短版里显得啰嗦 |
| "这本书很薄，一个下午就能读完" | **压成"这本书很薄"** | 前半句是节奏缓冲，后半句是行动暗示，各留一半 |

**一个字都没动的**：开场两句、森林之问、"没什么特别的"、"下楼走一趟"。

## 四、配音与停顿（决定成败的 8 处）

| 位置 | 停顿 | 说明 |
|---|---|---|
| 《假如给我三天光明》之后 | 0.8s | 让书名落地，观众手指停在屏幕上 |
| "也失去了声音。"之后 | 0.5s | 第一次沉 |
| "写下水的名字。"之后 | 0.6s | 全片唯一的呼吸口 |
| "看到了什么？"之后 | 0.8s | **最关键**，问号必须留白，不能连着下一句 |
| "没什么特别的。"之后 | 0.5s | 让平淡发酵 |
| "只剩三天光明。"之后 | 0.5s | 进入主体 |
| "她没有遗憾。"之后 | 0.6s | 情绪回收 |
| "是什么颜色。"之后 | 1.0s | 收尾留白，配黑屏或空镜 |

**语速曲线**：开场 4.0 字/秒（慢）→ 三天段 4.5（推）→ 结尾 3.8（收）。
**重音只有三处**：`水的名字`｜`没什么特别的`（要轻，越平淡越有力）｜`可我们从不抬头`。
**禁**：朗诵腔、上扬尾音、BGM 压过人声（建议 -22dB 以下，钢琴单音或环境声）。

## 七、这版的风险，先说清楚

1. **60 秒装不下"水井房"的完整情绪**。原版"一遍，又一遍"那种静默的力量，在短版里只剩一个交代性画面。如果这一条跑得好，长版可以作为"深度版"二发。
2. **三天段落变成清单感**。每天一行，节奏会快，容易变成"念课文"。靠配音放慢 + 每行一个画面镜头解决，分镜阶段我会做标记。
3. **结尾"这本书很薄"信息不完整**。短版删了"一个下午能读完"，可能会有人觉得突兀，可考虑保留原来的完整句（+6 字，不影响总时长）。
