## 三、文案全文（22.66 秒 / 110 字 / 14 行）

```
他最后一个去食堂，
买最黑的那个馍。

今日分享；
《平凡的世界》

孙少平读高中，
怀里揣着一本书。

夜里熄了灯，他借一点光，
一页一页往下读。

我们总说没时间，没条件，
他两样都没有。
可他一天都没停过。

书里写，最平凡的人，
也要为他生活的世界奋斗。

今晚睡前，读三页。
```

结构：钩子（食堂黑馍）→ 报书名 → 处境（揣书 / 夜读）→ 张力点（我们没时间、没条件，
他两样都没有）→ 原书句 → 收尾（今晚睡前读三页）。

两个判断：

1. **钩子不报身份**。「县立高中的穷学生」信息量太散，换成「最后一个去食堂 / 买最黑的那个馍」，
   两个动作全是可见的，观众自动会问「他为什么吃这个」。孙少平的名字压到报完书名再说。
2. **原书句放张力点之后**。先让观众被「他两样都没有」扎一下，再把「最平凡的人也要为他生活的
   世界奋斗」摆在后面接住——顺序反过来就成了先讲道理，没人愿意听。

## 七、这轮踩到的两个坑

1. **领句单独成行的代价**：原稿有「一身补丁，」「书里写，」「没条件，」「今晚睡前，」四个短领句，
   每个都占满一整行的 1.2 秒（含停顿），全片跑到 25.66 秒。合并成「书里写，最平凡的人，」
   这类 10—12 字的行之后，同样的字数压到 22.66 秒。**20—25 秒的片子，一行领句就是 1.2 秒，
   写文案时就要按「行」而不是按「字」算时间。**
2. **逐行响度不是每次都归位**。L04「一页一页往下读」和 L08「书里写，最平凡的人」首轮合成后
   比邻行低 4—5.6 dB（原始峰值也偏低，增益被 16 dB 上限卡住）。删掉该行缓存让 `fill_lines.py`
   重做一次即回到 ≤3 dB。**跑完一定看响度验收那三行，不要默认它会自己过。**
