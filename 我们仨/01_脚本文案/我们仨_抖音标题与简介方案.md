# 《我们仨》抖音标题与简介方案（条目 03）

> 沿用前两条验证过的标签策略：第一个挂书名标签，不挂泛流量标签。
> 本条 CTA 是**转发**，所以标题与简介都要把「那个人」具体化。

## 一、标题（第一行，主推）

```
她写这本书的时候，丈夫和女儿都已经不在了｜书单 03
```

备选两条：

```
我们仨失散了，她一个人思念了二十多年｜书单 03
```

```
把这条转给那个人吧，趁现在还来得及｜书单 03
```

第一条最稳：把书里最重的事实摊在第一行，不喊情绪，靠信息密度让人停手。
第二条最像“故事”，但「二十多年」是推算值（1998→2003 动笔），容易被较真的评论抓；
第三条是片尾原话，做标题会把转发动作提前消耗掉，评论反而没话说。

## 二、描述正文

```
“我们仨”其实只有三个人：钱锺书、杨绛，和他们的女儿钱瑗。

1997 年，女儿走了。1998 年，钱锺书走了。
杨绛 92 岁那年，把这三个人六十多年的日子写了下来。

书里没有情节。她写做饭，写散步，写谁先睡着。
她说：现在我们三个失散了。
她说：我一个人思念我们仨。

最日常的细节，最后成了最不敢碰的东西。

把这条转给那个人吧。趁现在还来得及。
```

## 三、标签（4 个，不要多挂）

```
#我们仨 #杨绛 #亲情 #书单
```

| AIGC 标识 | 勾选“内容由 AI 生成”（画面与配音均为 AI） |
| 发布时间 | 21:00-22:30（亲情类内容在睡前时段转发率最高） |

## 五、标签选择理由

1. **第一个必须是书名标签。** 书名搜索意图最强、竞争最小，0 粉阶段唯一稳定拿到精准长尾的入口。
2. **挂 #杨绛 而不是 #文学。** 作者标签是精准兴趣标签；#文学 会把内容丢进大池子当分母，且来的人期待的是书评长文，不是 30 秒视频。
3. **不挂 #好书推荐 / #书单推荐。** 这类标签引来的是“求书名”“有链接吗”，账号没橱窗接不住。
4. **挂 #亲情 是本条与前两条最大的不同。** 前两条是“自我”向（情绪、观点），这条是“关系”向；#亲情 的转发意愿显著高于收藏，正好对上本条 CTA。

## 六、评论区预埋（发布后 10 分钟内自己置顶一条）

```
书里最狠的一句其实不是“失散了”，是她说“我一个人思念我们仨”——
“我们仨”这三个字她一直没改口，还是三个人。
```

作用：把讨论从“好难过”推到“她为什么还叫我们仨”，这类具体问题最容易长出真实回复；
同时不给“求链接”留位置。
