## 三、配音处理要点

| 位置 | 处理 |
|---|---|
| 镜 1「都已经不在了」 | 放慢到 4.2 字/秒，「不在了」压音量轻轻落下，说完立刻收住 |
| 镜 2「一九九七年 / 一九九八年」 | 按年份平念，不数数、不带顿挫；两个年份同一语速同一音量，不做比对 |
| 镜 2「女儿走了 / 丈夫走了」 | 语气放平、「走了」不加重不上扬，避免变成哭腔 |
| 镜 3「失散了」 | 全片最慢，三字各自念清、字间略拉开，音量压低不发虚 |
| 镜 4「这本书没有情节」 | 唯一一处语速回升到 5.2，像翻相册的旁白 |
| 镜 5 三个「写」 | 三行等距同节奏，像在点数，不抢重音 |
| 镜 6「最不敢碰的东西」 | 「不敢碰」放慢压音量，说完收住、不叹气 |
| 镜 7「思念我们仨」 | 全片最慢 4.0 字/秒，「仨」轻轻落下，句尾平收 |
| 镜 8「趁现在还来得及」 | 收弱、不用重音——是轻轻建议，不是催促 |

三条硬规则（前两条已踩过，这里直接沿用）：

1. **停顿不写进 `line_hints`**。写「停半拍」会被模型念进音频，拼接层再按标点补一次，节奏断裂。停顿统一交给拼接层（`。`0.40s、`，`0.22s）。
2. **音色定稿后不为调音量重跑 TTS**。TTS 合成到 -18 dBFS，再用 `tools/gain_and_limit.py` 提到 -16 dBFS。
3. **年份一律写中文读法**，且含义先核对——念错了没法用字幕救。

## 四、CTA 设计

片尾只做一件事：**转发**。理由（方案 §四）：亲情类内容的转发是刚需，且转发带来的外部流量最优质。

措辞用「把这条转给那个人吧」，把动作落到一个具体的人身上（父母、伴侣、久没联系的人），
而不是抽象的「转发给朋友」；「趁现在还来得及」是这本书本身的分量，不是营销话术。

不喊关注、不提商品——账号未开橱窗，任何带货暗示都会把评论区变成问链接。
