## 七、改配置就能重出的东西

`project.json`：

```json
"overlays": [
  { "name": "标题层", "start": 0, "end": 61 },   // 书名常驻区间
  { "name": "书封层", "start": 0, "end": 8 }     // 书封出现区间，改 61 就全片常驻
]
```

字幕样式在 `captions.style`，清理规则在 `captions.text_cleanup`（`strip_tail_punct` / `strip_book_marks`）。

改完执行：

```bash
python gen_draft.py --dry-run          # 校验
python gen_draft.py                    # 生成草稿
python localize_draft.py <draft_id>    # 本地化素材（需先关剪映）
```
