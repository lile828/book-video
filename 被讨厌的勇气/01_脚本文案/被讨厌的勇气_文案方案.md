## 三、配音处理要点

| 位置 | 处理 |
|---|---|
| 镜 1「是推导出来的」 | 放慢到 4.5 字/秒，五个字略拉开，落地收住 |
| 镜 2「一个“好人”」 | 音量略收、带苦味、句尾降调，不反问式上扬 |
| 镜 3「你能反复想三天」 | 「三天」放慢轻轻落下，不加重（避免变成抱怨） |
| 镜 5「是你自己“选择”的」 | 「选择」单独加重，句尾降调 |
| 镜 6「比“改变”更安全」 | 「更安全」放慢压音量，说完停明显一拍 |
| 镜 7「就是被人讨厌」 | 全片最慢，四字等距，音量压低，后留长空白 |
| 镜 8「先收藏」 | 独立短句、干脆、音量略提 |

两条硬规则（上一本书踩过，这里直接规避）：

1. **停顿不写进 `line_hints`**。写“停半拍”会让模型把停顿念进音频，拼接层再按标点加一次，节奏断裂。停顿统一交给拼接层。
2. **音色定稿后不为调音量重跑 TTS**。TTS 合成到 -18 dBFS，再用 `tools/gain_and_limit.py` 提到 -16 dBFS。

## 四、CTA 设计

片尾只做两件事：**收藏 + 评论**。理由（方案 §四）：观点类内容值得存，收藏率是这类内容的算法加分项；
问句形式（“你最怕被谁讨厌”）比命令式更容易触发真实回答。

不喊关注、不提商品——账号未开橱窗，任何带货暗示都会把评论区变成问链接。
