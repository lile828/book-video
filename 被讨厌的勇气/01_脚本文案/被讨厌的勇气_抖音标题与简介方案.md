# 《被讨厌的勇气》抖音标题与简介方案（条目 02）

> 沿用条目 01 验证过的标签策略：第一个挂书名标签，不挂泛流量标签。

## 一、标题（第一行，主推）

```
一切烦恼都来自人际关系｜书单 02
```

备选两条：

```
所谓自由，就是被人讨厌｜书单 02
```

```
你不是懒，你是不敢被人讨厌｜书单 02
```

第一条最稳：话题本身是书里最硬的一句结论，搜索/兴趣双匹配，且不带年份、不带功效承诺。
第二条最像“金句”，但少了钩子；第三条最容易被点开，但“你不是懒”已经被条目 01 用过，重复会削弱系列感。

## 二、描述正文

```
一切烦恼都来自人际关系。

这句话听着像鸡汤，其实是推导出来的。《被讨厌的勇气》整本书，就是一个年轻人跟一位哲人吵了五个晚上，把这句话一步步拆给你看。

第一步：你的不幸，是你自己选的。不是因为懒，是因为"不幸"比"改变"更安全。
第二步：所谓自由，就是被人讨厌。

阿德勒心理学不讲过去，只讲你现在为什么还需要这个"不幸"。

你最怕被谁讨厌？
```

## 五、标签选择理由

1. **第一个必须是书名标签。** 书名标签搜索意图最强、竞争最小，0 粉阶段唯一能稳定拿到精准长尾流量。
2. **挂 #阿德勒心理学 而不是 #心理学。** 前者是精准的知识标签，后者会把内容推进大池子当分母；而且看 #心理学 的人期待的是科普，不是一本书。
3. **不挂 #好书推荐、#书单推荐。** 这类标签引来的是“求书名”“有没有链接”，账号没橱窗接不住，评论全变问句，互动率反而拖累推荐。
4. **不挂 #职场、#自我提升。** 上一次 55% 跳出率就是跨人群推流导致的：想看方法的人点开听到的是哲学对话，2 秒就走。

## 六、评论区预埋（发布后 10 分钟内自己置顶一条）

```
书里说“自由就是被讨厌”，其实还有后半句更狠——被讨厌不是目的，是代价。原文在第四夜，值得单独读一遍。
```

作用：把“求链接”的评论压下去，把讨论引到书的内容本身；同时给完播的人一个“原来还有一层”的钩子。
